# Cahiers

Application de prise de notes pour etudiants ingenieurs (formules, schemas, calculatrice).

Telechargez la derniere version dans l onglet **Releases** :
- Windows : `Cahiers_x.y.z_x64-setup.exe`
- Mac (puces Apple et Intel) : `Cahiers_x.y.z_universal.dmg`

L application se met ensuite a jour toute seule (bouton Mettre a jour).
